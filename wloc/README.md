# wloc

Apple WLOC 网络定位修改（gs-loc）的 Stash 覆写，自托管副本。

原作者 Yu9191 的仓库已下线，本仓库内容取自 fork [golfiishwb/wloc](https://github.com/golfiishwb/wloc)，仅把覆写里的链接改为指向这里。

## Stash 覆写链接

```
https://raw.githubusercontent.com/SurfenV/TestScrip/refs/heads/master/wloc/modules/wloc.stoverride
```

## 文件

- `modules/wloc.stoverride`：Stash 覆写
- `dist/wloc.js`：改写定位返回坐标的脚本
- `dist/wloc-settings.js`：保存定位设置的脚本
- `wloc.jpg`：图标

默认坐标写在覆写的 `argument` 里。建议用快捷指令设置自己的位置，不要把真实坐标提交到这里（仓库是公开的）。
